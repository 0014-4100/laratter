# 日記アプリ

受講番号：6th_09
氏名：大石 奈由

## 1. プロダクトの紹介

Laravelを使用して制作した日記アプリです。

日付ごとに写真とコメントを登録することができます。

登録した日記はカレンダーから確認することができ、
日記が登録されている日には「●」が表示されます。

また、前月・次月へ移動することができ、
日付を選択すると、その日の写真やコメントを確認できます。

ログインしているユーザー自身の日記のみ閲覧できるようにしています。

## 2. こだわった点・苦労した点

### こだわった点

カレンダーから日記を確認しやすいように、
日記が登録されている日に「●」を表示しました。

また、ブラウンとクリーム色を使用した
カフェ風のデザインにして、各画面の統一感を出しました。

### 苦労した点

Laravelでのデータベースとの連携や、
写真をアップロードして表示する処理に苦労しました。

また、1日に複数の日記を登録できないようにする処理や、
ログインしているユーザー以外の日記を閲覧できないようにする処理も実装しました。

## 3. 操作方法

1. ログインする。
2. 日記一覧を開く。
3. 「日記を作成する」を押す。
4. 日付、写真、コメントを入力する。
5. 「保存」を押す。
6. 日記が登録された日に「●」が表示されることを確認する。
7. 「●」が表示されている日付を押す。
8. 写真とコメントが表示されることを確認する。
9. 「← 日記一覧に戻る」を押して一覧に戻る。
10. 「前の月」「次の月」を押してカレンダーを移動する。
